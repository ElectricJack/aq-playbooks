# Remind the coordinators about waiting tasks

When a task is ready but nobody has been chosen to take it yet, wait a while.

Then look at the task again. If somebody has been chosen to take it by then,
there is nothing to do. If the task is gone, there is nothing to do either.

If it is still waiting, send the coordinators this message: "This task is
ready and has been waiting without anyone to take it."
