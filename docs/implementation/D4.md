# D4: Reconciled AQ host catalog

Task: `crisp-meadow-36.5`. Date: 2026-11-02. Repository: aq-playbooks.

The versioned [AQ host schema bundle](../../contracts/aq-host/README.md) is the
single executable registry used by the CLI, stateful fake host and four pilots.
It has twelve commands, seven events, five context views, nine work kinds and
six change variants. The formatted registry is 79,253 bytes, below 262,144.
Version `1.0.0` is bound to fingerprint
`sha256:627125cc393d8274bfaa9ffc785c338e566cc69af362ac027a3daa355c3509e1`.

The schema artifact has no sibling repository dependency. Consumers vendor its
JSON files at an exact source revision and decode with their pinned model crate;
no CLI/fake-host implementation is linked into production. The manifest digest
is canonical SHA-256 over `[version, registry]`; individual command/event
fingerprints use the model digest. Fixtures include valid/invalid schemas,
old-protocol incompatibility and immutable admission/replay vectors.

## Implementation and decisions

- `crates/aq-playbooks-cli/src/catalog.rs:75–89` embeds the published registry and
  exposes the version/fingerprint in the surface response.
- `contracts/aq-host/registry.json` fixes recovery to two Observation commands,
  nine KeyedIdempotent mutations, and Reconcilable publication. Identities bind
  immutable input and authority; publication requires authoritative reconciliation.
- Message enqueue uses `queued`; owned work and decisions distinguish accepted
  handles from business completion. Independent work retains `ensured` admission.
  Judgment remains synchronous (`assessed`) in this catalog version.
- `crates/aq-playbooks-cli/src/fake_host.rs:89–98,372–420,901–1022` adds durable
  async decisions, authorized revision-bound response, expiry/cancellation,
  immutable completion, lost-response recovery and typed operation readback.
- `crates/aq-playbooks-cli/src/pilots.rs` and host/admin tests consume
  `aq.operation.updated` from authenticated producer `aq.host.bridge@1` and
  `queued` message receipts. Routing and watcher consume the same captured
  registry without per-pilot modifications.
- `crates/aq-playbooks-cli/tests/host_pilots.rs:393–440` checks captured command
  and event equality and executes all four stateful pilots in
  `pilots_pass_on_reconciled_catalog`.
- `crates/aq-playbooks-cli/tests/catalog_contract.rs:6–158` verifies versioned
  fingerprint, schemas, finite vocabulary, resource bounds, replay vectors,
  identity conflict refusal and incompatible old contracts.
- [Host integration](../aq-host-integration.md#reconciled-aq-host-catalog-100-d4)
  documents every command outcome and all seven event names, authoritative
  sources, trusted producer, closed payload schema, subject/revision paths and
  exact operation-handle correlation.
